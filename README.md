# Michael Nnotum - Personal Portfolio

A responsive portfolio for Nnotum Otitodirichukwu Micheal, showcasing front-end development, UI/UX concepts, and selected creative projects.

**Live site:** [otitopersonalportifolio.edgeone.dev](https://otitopersonalportifolio.edgeone.dev/)

## About

The portfolio is a single-page website with Home, About, Projects, and Contact sections. It includes project previews, links to selected live sites and Figma work, and direct contact and social links.

Featured work includes Kemomem Trading, Gist Talk, Otix Shopping Website, interface and mobile UI concepts, Python project previews, and personal branding.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Poppins and Space Grotesk

The page styles and navigation behavior are included in `index.html`. The site has no package manager or build step.

## Run Locally

Open `index.html` in a browser, or serve the folder with any static file server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Project Files

- `index.html` - Main portfolio page.
- `index.html.md` - Markdown version of the portfolio content.
- `llms.txt` - Text overview and links for AI tools.
- `robots.txt` and `sitemap.xml` - Search engine discovery files.
- Image files in the repository root - Project previews, profile images, and branding assets used by the site.

## Deployment

This is a static website. Deploy the repository's files to a static hosting provider and make sure `index.html` is served as the site entry point. The current canonical URL and metadata refer to the live EdgeOne site, so update them in `index.html`, `sitemap.xml`, and `llms.txt` if you deploy to a different domain.
